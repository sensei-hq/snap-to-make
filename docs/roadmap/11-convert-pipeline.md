# Stage 11 — Convert pipeline: image/description → agreed objective → breakdown · AUTO→HANDOFF(samples)

Entry points (both start the same flow):
- **Drop/import**: drag-drop or file picker (image) on `/snap/convert`; **Camera**: getUserMedia snapshot.
- **Description only**: text describing what to achieve (no image).
Then: **comments** (what it is, what to change) → Spark proposes an objective + **3 variations** →
user agrees one → deterministic **breakdown** (pieces, materials, tools, assembly/combine instructions)
→ Object → Impl (adapter) → Simulate/Make as before.

Groups: `laser-cut` | `cricut-paper` | `shrink-plastic`.
Classes: `layered` (extract stacked layers) | `composite-3d` (extract joined faces) | `pattern-shape` (single flat pattern).

Shrink plastic: the cut/drawn design must be **larger** than the final piece. `design_mm = final_mm / shrinkRatio`
(ratio = final/design, default 0.40, calibrated per material: bake a 100 mm test tile, measure, ratio = measured/100).
All dims, holes and line widths scale; expected final size is shown next to every cut size. Oven step in instructions.

Sample set: `samples/` (images git-ignored, local only). Classification manifest: `samples/manifest.local.json` (git-ignored)
(generated by live Spark vision; regeneration script in git history of this stage — never commit the images).

Server: `POST /api/convert {imageDataUrl?, description?, comment?, group}` → live Spark vision (structured
`ConvertProposal`) when key present, deterministic fallback otherwise.
